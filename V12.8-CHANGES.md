# Objavuj 12.8 – prihlásenie heslom

- E-mail a heslo ako predvolený spôsob prihlasovania cez Supabase `auth.signInWithPassword()`.
- Magic Link zostáva záložnou možnosťou.
- Po úspešnom prihlásení sa používa pôvodná perzistentná Supabase relácia a knižnica.
- Nepridávame automatickú registráciu. Existujúcemu používateľovi bolo heslo nastavené administrátorsky.
- **POZOR:** `config/supabase.json` v tomto release ZIP nie je, aby sa pri použití deploy skriptu neprepísala skutočná URL a publishable key. Súbor má zostať zo súčasnej vetvy `main`.
- Pri výpadku internetového pripojenia/častom obnovovaní môže cache service worker zobrazovať starý HTML obsah; použite tvrdé obnovenie.
