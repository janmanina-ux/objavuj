# Objavuj 12.7 – obnova prihlásenia

- Pri návrate z Magic Linku rozpoznáva autentifikačné chyby a zobrazuje ich používateľovi.
- Explicitne používa implicitný browser flow a zachováva reláciu v úložisku prehliadača.
- Po návrate na kartu / obnovení stránky znovu kontroluje aktuálnu reláciu.
- Po úspešnom prihlásení čistí citlivé parametre z URL bez zmeny obsahu relácie.
- Nezasahuje do Supabase SQL ani do prekladovej Edge Function.

**Poznámka:** Staré alebo už použité Magic Linky nemožno obnoviť; na prvé úspešné prihlásenie môže byť potrebný nový odkaz.
