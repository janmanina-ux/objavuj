# Objavuj 12.2 — ďalšie zdroje bez nefunkčných RSS

- Samostatná sekcia **Objavuj ďalšie zdroje** s 8 tematickými rozcestníkmi.
- Odkazy na MTBIKER, Hiking.sk, Frontman, Vedátor, ASB a Europe Class bez predstierania automatického RSS importu.
- `data/discover.json` je statický, ručne spravovaný katalóg, a **nie** denné spravodajstvo.
- Workflow publikuje discover.json spolu s existujúcim RSS/AI feedom.
- Zmena cache verzie service workera pre spoľahlivejšie obnovenie UI.
- Existujúci GitHub workflow, tajomstvá a limity AI ostávajú nezmenené.

## Nasadenie

`~/bin/deploy-objavuj.sh ~/Downloads/objavuj-v12.2.zip`

Po merge PR skontroluj `https://janmanina-ux.github.io/objavuj/data/discover.json` a sekciu **Objavuj ďalšie zdroje**.

Poznámka: táto verzia ešte **nesťahuje** obsah webov, ktoré neposkytujú funkčné RSS. To by vyžadovalo samostatné podporované API, povolené sitemapy alebo explicitné overenie podmienok vydavateľa.
