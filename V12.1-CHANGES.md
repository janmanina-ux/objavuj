# Objavuj 12.1 – RSS hotfix

- Odstránené z aktívneho importu: MTBIKER, Frontman, MTHIKER (HTTP 404). Ich konfigurácia zostáva archivovaná v `feeds-disabled.json`.
- Horydoly zmenené na oficiálne uvádzanú RSS adresu `https://www.horydoly.cz/rss` (bez koncovej lomky). **Živú funkčnosť musí potvrdiť prvý beh GitHub Actions.**
- Veda na dosah a ASB ponechané bez zmeny.
- Existujúci feed sa pri výpadku zdroja zachová podľa doterajšieho fallback mechanizmu.
- Nijaké zmeny AI spracovania, API kľúčov ani publikačnej vetvy.

## Nasadenie

`~/bin/deploy-objavuj.sh ~/Downloads/objavuj-v12.1.zip`

Po úspešnom deployi overiť `data/latest.json`: `configured_sources` má byť 3. Ak Horydoly zlyhá, v errors zostane iba tento zdroj.

MTBIKER je naďalej dostupný ako redakčný web s cyklistickými a outdoorovými článkami, ale potvrdenú platnú RSS URL teraz nemáme. MTHIKER sa medzitým zlúčil s MTBIKER.
